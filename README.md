# 🎬 Ninzywangy - Professional Video Editor APK

Aplikasi video editing profesional untuk Android dengan fitur-fitur lengkap seperti Alight Motion.

## ✨ Fitur Utama

### Video Editing
- ✅ Frame by Frame Editing
- ✅ Keyframe Animation System
- ✅ Multiple Layers Support
- ✅ Timeline Editor dengan Zoom Control
- ✅ Video Trimming & Cutting
- ✅ Speed Control (0.25x - 2x)

### Effects & Transitions
- 🎨 20+ Built-in Effects
- 🎭 Smooth Transitions
- ✨ Particle Effects
- 🌈 Color Grading
- 📐 Transform Effects (Scale, Rotate, Skew)
- 🔄 Blend Modes

### Text & Animation
- 📝 Text Animation
- 🎯 Motion Text Effects
- 📊 Shape Layer Support
- 🎪 Keyframe Interpolation
- 🔀 Bezier Curve Control
- ⏱️ Animation Timeline

### Audio
- 🎵 Multi-track Audio
- 🔊 Audio Mixer
- 📈 Audio Equalization
- 🎙️ Voice Recording
- 🔗 Audio Sync

### Export
- 📱 Export ke Video (MP4, WebM)
- 📸 Export ke Image Sequence
- 🎬 Preset Resolutions (720p, 1080p, 4K)
- ⚙️ Custom Export Settings
- 📤 Share Langsung ke Social Media

## 🚀 Quick Start

### Requirements
- Android Studio 4.0+
- Android SDK 24+
- Gradle 6.5+
- Java 8+

### Installation

```bash
git clone https://github.com/inffamily210-pixel/ninzywangy.git
cd ninzywangy
```

### Build APK

```bash
./gradlew build
./gradlew assembleRelease
```

## 📱 Tech Stack

- **Language**: Java/Kotlin
- **UI Framework**: Android Material Design 3
- **Video Processing**: FFmpeg, ExoPlayer
- **Graphics**: OpenGL ES, Canvas
- **Database**: Room Database
- **State Management**: ViewModel, LiveData
- **Async**: Coroutines, RxJava
